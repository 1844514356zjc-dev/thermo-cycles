# 模型、公式与适用范围

所有温度 K、压力 Pa、比焓 J/kg、比熵 J/(kg·K)、功率 W、质量流量 kg/s。
默认质量流量 1 kg/s。正号约定：吸热、排热和净输出功均为正。

## 压气机、泵、涡轮

给定入口与出口压力，CoolProp 计算 `h_2s = h(p_2, s_1)`。

- 压气机/泵：`eta_c = (h_2s-h_1)/(h_2-h_1)`。
- 涡轮：`eta_t = (h_1-h_2)/(h_1-h_2s)`。
- 轴功由真实焓差得到，泵不使用不可压缩近似。
- 机器绝热，无机械/发电机效率损失，无动能与位能变化。

## 回热与压损

等质量流量逆流回热器：`q = epsilon*q_max`，`h_c,out=h_c,in+q`，`h_h,out=h_h,in-q`。
每个换热部件 `p_out=p_in*(1-delta)`。先由压力闭环确定涡轮背压，再求回热，避免忽略低压侧压损。
最大可回收热量同时受两端焓差与内部夹点约束。逆流坐标 x 从冷入口指向冷出口：

`h_c(x)=h_c,in+x*q`，`h_h(x)=h_h,in-(1-x)*q`。

两侧压力沿各自流向线性变化，在 201 个站位计算真实温差，以 SciPy Brent 根求解无温度交叉的 q_max。不是恒定 cp 或固定理想气体 gamma 模型。
这是离散夹点近似；极端近临界工况应提高站位数做收敛研究，不能宣称连续域夹点的严格保证。无回热驱动力时旁路换热，但保留用户指定压损。

## 能量和㶲

`w_net=w_t-w_c/p`，`q_in=h_heater,out-h_heater,in`，`q_out=h_cooler,in-h_cooler,out`。
`eta_th=w_net/q_in`，能量残差 `q_in-q_out-w_net`。

环境基准为 `(T0,p0)`，热源 TH、冷源 TC 是恒温无限热库。热源/冷源温度必须与沿程传热方向一致。
状态物理㶲 `e=(h-h0)-T0*(s-s0)`；不含化学㶲。

- 绝热机器：`ED=T0*(s_out-s_in)`。
- 回热器整体：`ED=T0*(Delta_s_cold+Delta_s_hot)`，不把两侧单独当作绝热部件。
- 加热器及其热源：`ED=T0*(Delta_s-q_in/TH)`。
- 冷却器及其冷源：`ED=T0*(Delta_s+q_out/TC)`。
- 热输入㶲 `E_in=(1-T0/TH)*q_in`。
- 排热㶲 `E_out=(1-T0/TC)*q_out`，TC=T0 时为零。
- `eta_II=w_net/E_in`，它是以净轴功为产品的㶲效率。
- 㶲残差 `E_in-E_out-w_net-sum(ED)`。

ED 的单位为 J/kg，乘质量流量才是 W。换热器 ED 包含从恒温热库传热的不可逆性；改变热库模型会改变 ED 与㶲效率，因此它们不能仅由循环四个状态唯一确定。

## 循环和相态

Brayton 是闭式外加热循环，不是燃烧/混合的开式燃气轮机。Rankine 是简单朗肯循环，无抽汽回热。冷凝器出口用 P,Q=0，饱和蒸汽入口可设 turbine_inlet_temperature=None，避免饱和线上 P,T 闪蒸歧义。

Air、CO2、R134a、Water 均调用相同真实流体接口，但必须分别选用物性有效范围内的循环参数。常温 Air 没有液态冷凝器，不能作为普通常温朗肯工质；CO2 亚临界冷凝循环需要低于临界温度的冷源。程序拒绝无净功或明显违反第二定律的输入。

仅面向纯工质与 CoolProp 支持的伪纯工质，不支持任意组分混合物的相包络。湿膨胀可计算并报告出口干度，但不包含液滴侵蚀或非平衡凝结模型。

## 绘图精度边界

换热器路径采用线性 h 与 p 进度，机器采用线性 h、对数 p 插值，再逐点做真实物性闪蒸。增加 points 提高采样密度；密集点数不代表机器内部过程已被辨识，端点效率不足以唯一决定内部路径。

两相交点用饱和焓与路径焓的差做根定位；沸腾和冷凝段包含真实的两相温度/熵，避免直接在 T-s 平面画直线。饱和包络默认每支 400 点，避开三相点和临界点各 0.01 K。Air 是伪纯工质，液/汽支线有温度滑移，不能当作严格单组分饱和穹顶。包络用 T,Q 直接闪蒸以避免低温 Air 的 P,Q 反算失败。

参考：[CoolProp 官方 High-Level API](https://coolprop.org/coolprop/HighLevelAPI.html)，物性键与饱和输入规则。当前数值测试不替代实验验证。

## 边界工况与输入域补充

压比现在允许恰好1。当所有压损为0且仍有正外部吸热时，两台机器均无压变/无功，返回净比功0、两种效率0，并附退化工况提示。若无压缩却指定了需要额外背压的损失，压力闭环不可行，仍报 CycleError。零吸热的完全退化闭环因效率分母为0而拒绝。

T 输入现在显式要求不低于 max(Tmin,Ttriple)，错误信息包含工质和温度阈值。本项目选择不支持固相或低于三相温度的亚稳态计算；这是一项保守的模型域约束，并不意味着三相温度以下不存在气体。无效工质统一封装为 CycleError。效率100%只使机器可逆；有限温差换热器仍可能产生㶲损。
